# 脑梗恢复 · 脑梗康复训练

本项目通过整理实用护理技巧与健康科普，为卒中家庭、脑梗患者提供科学系统的照护指南与脑梗康复训练参考。

**这是一个开源项目，欢迎任何人阅读、浏览、取用。只要能帮到一个患者，就是有意义的。**

---

## 这个项目做什么

**只做零风险的照护常识。不生成训练处方，不做诊断，不评估疗效。**

对一个没有康复师的家庭，最先造成伤害的从来不是"训练没练到位"，而是：

| 常见错误 | 后果 |
|---|---|
| 躺着喂饭 | 误吸 → 卒中相关性肺炎（急性期发生率 7%~22%） |
| 拉患侧胳膊扶人 | 肩关节半脱位，不可逆疼痛 |
| 不翻身 | 压疮 |
| 不知道良肢位 | 关节挛缩，永久性 |
| 自行停药 | 复发（复发率约 17.7%） |
| 家里没扶手 | 跌倒骨折 |
| 认不出复发 | 错过 4.5 小时溶栓窗 |

这些全是**照护常识**，不是康复训练。零技术风险、零合规风险，而救命效果远大于多做几组屈肘。

这正是"有康复师"和"没康复师"之间那道鸿沟的真实形状——
有康复师的家庭，这些会被一条条告知；没有的家庭，出院时只有一张纸和五分钟叮嘱，而家属那天正处在震惊里，一个字都记不住。

## 当前状态

主线已经从单页网页转成**微信小程序**，代码在 [`miniprogram/`](miniprogram)。
微信开发者工具导入该目录即可运行，无需装依赖、无需构建。详见 [`miniprogram/README.md`](miniprogram/README.md)。

小程序共 8 个页面，四个模块各管一件事：今天要做的、今天的训练（8 个动作）、请一定要知道（10 张知识卡）、记录（里程碑与累计）。
**没有后端、没有网络请求、不采集任何数据**，所有记录用 `wx.setStorage` 存在用户自己手机上。

早期的单文件网页原型保留在 [`prototypes/`](prototypes)，仍是所有插图 SVG 的源头。

设计原则：

- **多图少字** —— 面向老年人、低识字度、震惊状态下的家属
- **不切换身份** —— 就是给照护者一个人用的
- **只做最安全的** —— 见 [`docs/安全边界.md`](docs/安全边界.md)

## 想参与

### 让更多人够得着（很需要人做）

小程序只覆盖了会用微信的人。还有很多家庭不在这个范围里：

- **PC 版网页** —— 把小程序的内容做成一个能在电脑浏览器打开的版本。
  很多家属是在单位电脑上、在住院部的公共电脑上找信息的；医生想转给患者，也需要一个能直接发的链接。
  内容全在 `miniprogram/utils/` 的几个 js 文件里，页面结构见 [`miniprogram/README.md`](miniprogram/README.md)。
- **可打印版** —— 一份能 A4 打出来、贴在床头或塞进出院袋子里的纸质版。
  这可能是最被低估的一件事：老人不用智能手机、护工没时间翻手机、家属在病房里手忙脚乱，
  但一张贴在墙上的图，每天会被看见很多次。
  排版要求和小程序一致 —— **多图少字、字要大**。
- 其他任何能降低获取门槛的形式都欢迎：适老化大字版、方言语音、给社区护士用的宣教材料。

做这些不涉及安全边界的判断，是最容易上手的贡献。

### 让内容更靠得住

1. **补文献** —— [`docs/待获取文献清单.md`](docs/待获取文献清单.md) 里列了抓不到全文的文献，标题都是精确的
2. **挑错** —— 任何一条剂量、数字、说法有问题，请开 Issue，标注出处
3. **提照护场景** —— 你在照顾脑卒中家人时踩过的坑，可能正是别人明天要踩的

新增或改动内容之前，请先读 [`docs/安全边界.md`](docs/安全边界.md)。凡是越过第一层（零风险照护常识）的内容，都不会被接受。
