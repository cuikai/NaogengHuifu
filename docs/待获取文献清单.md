## 怎么搜最快

1. **万方 / 维普 / CNKI** —— 直接粘标题，多数指南类文献可以免费看或几元下载
2. **medlive.cn（医脉通）指南频道** —— 中文指南最全的免费库，需要注册，
   高龄那份 PDF 页脚就印着 `guide.medlive.cn`
3. **MedSci 指南频道** —— 上面那份居家环境指南就在这儿
4. **微信搜「指南全文」** —— 很多学会公众号会推全文，反而最容易拿到
