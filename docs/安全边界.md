# 安全边界

> 这是项目最重要的一份文档。任何新增内容都必须先过这一关。

面向没有康复师的家庭做康复，最大的诱惑是"那就让软件当康复师"。
**做不到，而且会出人命。** 所以内容必须按风险分层。

---

## 三层模型

### 第一层：可以给，而且必须给

零风险、无需个性化、无需专业判断。**这是项目当前的全部范围。**

- 照护常识（喂食姿势、翻身、搬动方法）
- 并发症预防（误吸、压疮、挛缩、肩关节半脱位、深静脉血栓）
- 良肢位摆放的**基本原则**
- 二级预防用药依从与血压监测
- 家居环境改造与防跌
- 卒中复发识别（FAST）与急救行为
- 康复知识与预期管理（为什么必须练、黄金期是什么）

判断标准：**这条内容对任何一个卒中患者都成立吗？做错了会不会立刻造成伤害？**

### 第二层：需要远程专业确认，谨慎

- 被动关节活动度维持
- 坐位平衡

要求：严格教法 + 自我筛查问卷 + 有康复师异步确认过。
**在项目具备远程康复师协作机制之前，不做这一层。**

### 第三层：无专业人在场，绝不提供

- **站立训练、步行训练** → 跌倒 → 老年髋部骨折 → 一年内死亡率极高
- **吞咽训练** → 误吸 → 可直接致命
- 任何需要判断肌张力、痉挛程度、Brunnstrom 分期的内容
- 任何形式的功能评分、分级、预后判断

**这是死线。碰了就从做好事变成害人。**

## 措辞红线

| 不能说 | 应该说 |
|---|---|
| 「本工具帮助恢复功能」 | 「本工具用于记录和提醒」 |
| 「改善偏瘫」「促进康复」 | （不提疗效） |
| 「您的恢复情况良好」 | 「本月记录了 21 天」 |
| 「建议加大训练量」 | 「复诊时可以和康复师讨论」 |
| 「根据您的情况推荐…」 | （不做个性化推荐） |

一旦出现疗效宣称或个性化治疗建议，产品性质就可能被认定为**医疗器械软件**，
需要二类注册；同时个人也无法承担相应的法律责任。

## 每条内容上线前的检查表

- [ ] 属于第一层吗？
- [ ] 对所有卒中患者都成立，还是需要因人而异？
- [ ] 如果用户完全照做且做错了，最坏后果是什么？
- [ ] 有没有隐含的疗效宣称？
- [ ] 有没有替用户做医学判断？
- [ ] 危险信号（何时必须找医生）写清楚了吗？
- [ ] 出处是公开可查的权威资料吗？

## 关于"要不要做训练内容"

**结论：不自己编，也不从英文数据库翻译。**

合法且安全的三个来源：

1. **康复治疗师针对本人开的处方**（最优）
2. **出院时病房护士的当面示范**——最实际的做法是引导家属**用手机拍下来**
3. 公开指南中的**原则性**内容（可以讲原则，不可以当处方使用）

长期方向不是"用软件替代康复师"，而是**用软件把一个康复师的产能放大 50 倍**：
家属拍 30 秒视频 → 志愿康复治疗师异步批量查看 → 给出分级方案 → 软件负责执行与记录。
一个治疗师一小时能覆盖几十个家庭，而不是面对面看三个。

这既安全、合规，也才是"让没有康复师的人有康复师"的真解。
