# 脑梗康复训练动作 · 动画生成提示词

> 本文档用于为 Seedance 等 AI 视频/动画生成工具提供提示词，生成 8 个康复训练动作的教学动画。
> 所有动作均面向脑卒中居家康复，强调「安全、缓慢、清晰」。

---

## ⚠️ 输出方案说明（生成前必读）

**本项目的运行载体是微信小程序，因此不输出 GIF。** 每个动作输出以下两类文件：

| 类型 | 用途 | 为什么不用 GIF |
|------|------|--------------|
| **静态封面图（JPG）** | 小程序列表页/卡片上默认展示，用户点击后才加载视频 | GIF 256 色有颗粒感、体积是 MP4 的 2-3 倍、无法控制播放暂停，且 8 个 GIF 会直接撑爆微信小程序 2MB 主包上限 |
| **循环短视频（MP4）** | 用户点击封面后，在详情页静音循环播放 | 见下一章详细技术规格 |

**最终交付物（每个动作 2 个文件）**：
```
ankle-cover.jpg      踝泵 - 封面图
ankle-loop.mp4       踝泵 - 循环视频
grip-cover.jpg       握拳伸展 - 封面图
grip-loop.mp4        握拳伸展 - 循环视频
...（共 8 动作 × 2 = 16 个文件）
```

## 一、通用全局设定（每个动画都需要包含）

### 输出格式与技术规格（每个动作必须严格满足）

**A. 静态封面图（× 1 / 动作）**
- 格式：JPG（基线 baseline，非逐行 progressive）
- 色空间：sRGB
- 尺寸：**720 × 720 px 正方形**（适配微信小程序卡片、列表、朋友圈分享图）
- 质量：80%-85%，不要 100%（体积爆炸）
- 单张体积目标：**≤ 80KB**，上限 120KB
- 画面内容：取该动作**顶点位置（最大幅度处）的定格画面**，右下角保留动作提示文字，确保不点开视频也能看懂大概做什么

**B. 循环短视频（× 1 / 动作）**
- 格式：MP4（容器 MPEG-4 Part 14，文件扩展名 `.mp4`）
- 视频编码：**H.264 / AVC（High Profile @ Level 3.1）** —— 微信小程序全机型兼容的黄金标准
  - ❌ 不要用 H.265/HEVC（iOS 部分老机型、Android 低端机硬解失败）
  - ❌ 不要用 VP9 / AV1（微信小程序内核不支持）
- 音频：**必须无音轨 / 静音**（不需要环境音、不需要音乐、不需要语音，加了也要删掉）
  - 微信小程序 `<video>` 默认静音自动播放在 iOS 上不稳定，但「无音轨的 MP4」100% 可以静默自动播放
- 色彩：YUV 4:2:0, 8-bit
- 分辨率：**960 × 540 px（16:9，横屏）** 或 **720 × 720 px（正方形）**，任选一种但 8 个动作要统一
  - 为什么不做 1080P：小程序卡片宽度一般在 320-380px，540P 已足够「视网膜清晰」，1080P 白翻 4 倍体积
- 帧率：**24 fps**（康复动作慢，30fps 没必要）
- 时长：**精确 1 个完整循环 = 3~4 秒**（按各动作的节奏要求）
  - 只做 1 次循环的内容，不要重复 2 次拼接（小程序端 `<video loop="{{true}}">` 会循环）
- 码率（目标）：**800 kbps ~ 1200 kbps**（恒定质量 CRF 23-26 优先）
- 单个 MP4 体积目标：**≤ 400KB**，上限 600KB
- **循环连续性（强制要求）**：
  - 视频的**第一帧和最后一帧画面必须完全一致（或极接近）**，否则小程序循环播放时会出现明显的「跳一下」
  - 收尾动作要慢慢回到起始位，不要突然截断
- 元数据：删除所有 EXIF、XMP、GPS 等元数据（ffmpeg `-map_metadata -1`）
- 关键帧间隔（GOP）：建议 1 秒 1 个关键帧（即 24 帧/ GOP），拖动进度条时响应更快

**体积超标时的压缩优先级（从上往下尝试）**：
1. 码率从 1200 → 1000 → 800 kbps 依次降（CRF 24 → 25 → 26）
2. 分辨率从 960×540 降到 800×450（不建议低于此）
3. 帧率从 24 fps 降到 20 fps（慢速动作肉眼几乎看不出区别）
4. 再不达标，用 HandBrake / ffmpeg 做二次压缩，不要在 Seedance 里反复改提示词

### 角色设定
- 中老年东亚人面孔（60-70 岁），神态平和，表情放松
- **人物全程睁眼**，眼神自然、清醒、平静；允许少量自然眨眼，但**不要出现闭眼停留、眯眼、睡着感**
- 体型偏瘦或中等，不做夸张肌肉表现
- 穿着宽松病号服或居家服（浅蓝色或浅灰色系）
- **重要颜色区分**：
  - 患侧（瘫痪侧）肢体用 **橙色/暖橘色** 袖套或裤腿标识
  - 健侧肢体用 **蓝色/天蓝色** 标识
  - 方便用户一眼区分哪侧是需要重点关注的

### 场景与环境
- 明亮整洁的卧室或病房，白色/浅米色墙面
- 一张标准病床（白色床单、木质或金属床架），视角固定为 **正面侧视 45° 角**（可以看清动作的完整轨迹）
- 背景简洁无杂物，可有一个床头柜 + 一杯水，不要其他干扰元素
- 自然光从侧窗照入，光照均匀不刺眼

### 画面风格
- **2.5D 简约矢量风格** 或 **写实但线条清晰的卡通写实风格**
- 色彩干净、对比适中，不要有过度的阴影和质感渲染
- 关键关节位置（肩、肘、腕、髋、膝、踝）可以加 **浅色小圆点** 高亮，让用户看清「哪里在动」
- 动作轨迹可以用 **淡蓝色虚线圆弧** 辅助标注（可选，但动作幅度大的建议加）

### 运动节奏（非常重要）
- **全程慢速、匀速、平稳**，不加速、不甩动、不用猛劲
- 每个完整循环（起始→动作→回到起始）控制在 **3-4 秒**
- 在动作的**顶点位置（最大幅度处）停留约 0.5 秒**，让用户看清做到什么程度算「到位」
- 呼吸训练动作稍慢，完整循环 4 秒
- 桥式运动在顶点停留 1 秒（对应「停 5 秒」的提示，但动画里压缩到 1 秒避免拖沓）

### 安全红线（所有动画共同遵守）
- 不要出现任何表情痛苦的画面
- 不要出现憋气脸红的样子（桥式和呼吸训练尤其要注意表情自然）
- 动作幅度做到「有点紧但不疼」的程度即可，不要追求极限角度
- 双手叉握上举**只举到胸口高度**，绝对不要举过头顶

### 其他通用元素
- 画面右下角可以出现大号文字提示（如「停 2 秒」「患侧拇指在上」），字体圆润清晰
- 每个动画以**循环播放**为前提设计，首尾帧自然衔接

### 文字稳定性（强制要求，已发现模型会乱改文字）
- **文字一旦出现，全程必须保持完全一致**：字体、字号、内容、位置、颜色，从头到尾不允许有任何变化
- **严禁文字乱码、变形、模糊闪烁、中途改写**（Seedance 容易在第 2 帧之后把文字变成乱码或其他字，必须在提示词中强制锁定）
- 画面中的文字（包括右下角提示、关节圆点旁的标签、颜色说明）在**第一帧就全部出现**，之后保持原样直到最后一帧
- 可以理解为：文字是「贴」在画面上的静态贴纸，不是动画元素

## 二、可直接投喂 Seedance 的 8 段提示词

> 下面每一段都可以单独复制，直接喂给 Seedance。每段都已经包含：微信小程序用的视频规格、封面图要求、以及「人物全程睁眼」的限制。

### 1. 踝泵

> ⚠️ **先试「标准版」再试「备用版」**：之前加了太多「禁止/黑名单/出错即重画」类负面词，疑似触发了 Seedance 的内容过滤器导致直接拒绝生成。先用下面的标准版（全正面描述、无负面指令），如果出图内容正确就不用看备用版；如果标准版画出来腿抬了或关节不对，再用备用版。

#### 标准版 · 全正面描述（推荐先用，过审率最高）
```text
脑卒中居家康复教学动画，2.5D 简约写实风格，明亮整洁病房，45 度侧视病床视角。中老年东亚患者平躺在床上，人物全程睁眼，眼神自然清醒。右腿（患侧）用橙色裤腿标识，左腿（健侧）用蓝色裤腿标识。镜头显示膝盖以下，聚焦小腿和双脚。小腿、膝盖、大腿自然伸直平放在床上，小腿轻压床单，下方床单有柔和的接触感。动作：仅踝关节和双脚缓慢运动——双脚同时勾脚尖（脚背朝向小腿方向），到最大幅度停 0.5 秒；回到中间；双脚同时绷脚尖（脚背向下、脚尖向远伸，脚跟仍贴床），到最大幅度停 0.5 秒；回到起始位。全程慢速平稳匀速，踝关节处用浅色圆点标注，脚尖运动轨迹用淡蓝色虚线弧标注。画面右下角有文字提示："勾脚尖停2秒 · 绷脚尖停2秒"，字体圆润清晰，颜色深蓝。输出：1 张 720×720 JPG 封面图（质量 85%，≤80KB，取勾脚尖到最大幅度的定格画面，保留文字提示）+ 1 个 MP4 循环视频（H.264 High Profile L3.1、24fps、无音轨、960×540 或 720×720、时长精确 3 秒、首尾帧几乎一致、单文件 ≤ 400KB、删除全部元数据）。
```

### 动作 1：踝泵（Ankle Pumps）
**目的**：促进下肢血液回流，预防深静脉血栓；防止踝关节挛缩。
**剂量**：20 次/组 × 3 组，一天 3 次。

#### 提示词
```
医疗康复教学动画，2.5D 简约风格，45°侧视病床视角。
中老年患者平躺在病床上，神态放松，右腿（患侧，橙色裤腿）和左腿（健侧，蓝色裤腿）都自然伸直放在床上。
特写镜头，膝盖以下占满画面，聚焦小腿和双脚。

【最优先约束（违反任何一条直接判定失败，必须重画）】
- 双腿（尤其患侧橙色裤腿那条）从大腿 → 小腿 → 脚跟 全程贴紧床面，小腿下方的床单能看到轻微的被压出的褶皱/凹陷，证明腿是压在床上的。
- 膝窝（膝盖后方的窝）和床面之间绝对不能有空隙，不允许出现「腿下能看到一条黑线或床面阴影」的画面。
- 绷脚尖时，脚跟也必须压死在床面上，只有脚踝和前脚掌/脚尖在动——绝对不允许因为绷脚尖而把脚跟抬起来。
- 患侧（橙色裤腿）和健侧（蓝色裤腿）两条腿的高度必须完全一致，不能患侧比健侧高。

【核心动作限制（出错即重画）】
- 小腿、膝盖、大腿全程完全固定不动，膝盖不弯、大腿不抬、小腿不左右或上下晃动，整条腿像被钉死在床面上。
- 只有踝关节和脚可以活动，绝对不允许膝关节参与运动。
- 【错误画面黑名单（出现任一即失败）】：膝关节弯曲、整条腿上下摆动、患侧腿抬高、脚跟离开床面、小腿与床面之间出现空隙或阴影、脚踝画圈旋转、患侧腿明显高于健侧腿。

动作循环：
1. 起始位：双脚自然放松，脚尖朝前。
2. 勾脚尖（背屈）：双脚脚尖同时用力往回勾（脚背朝向小腿方向弯），勾到最大幅度，停 0.5 秒，能看到小腿后侧肌肉被拉紧。
3. 回到中间，稍作停留。
4. 绷脚尖（跖屈）：双脚脚尖同时用力往下绷（脚背往下压、脚尖向远伸直，像踩油门但只有脚尖和脚踝在动，脚跟绝不离地），绷到最大幅度，停 0.5 秒，能看到小腿前侧肌肉收紧。
5. 回到起始位。

节奏：匀速缓慢，完整一个循环 3 秒。
细节：踝关节处用浅色圆点标注关节位置；只有脚尖和脚踝的运动轨迹用淡蓝色虚线弧标注；小腿与床单接触处可加 1-2 条淡淡的压痕线强化「腿压在床上」的视觉。
画面右下角文字：「勾脚尖停2秒 · 绷脚尖停2秒」，文字全程不变、不模糊、不乱码。
背景：简洁病床床单，无干扰。
风格：色彩干净，线条清晰，无夸张渲染。

======== 输出要求（不要忽略）========
【封面图】720×720 px 正方形 JPG，质量 85%，≤ 80KB，取「勾脚尖到最大幅度」的定格画面（动作顶点），保留右下角文字提示，且必须能看到小腿下方有床单压痕以证明腿没抬起来。
【短视频】MP4 / H.264 High Profile L3.1，960×540 px（或720×720 px），24 fps，时长精确3秒，1个完整循环，第一帧=最后一帧用于无缝循环，800~1200 kbps，无音轨，单文件 ≤ 400KB，删除所有元数据，全程静音。
```

#### 关键要点
- 两只脚**同时做**（不要只做患侧，健侧也一起）
- 幅度：勾脚到自己能感觉到小腿后侧拉紧即可，绷脚到前侧收紧即可
- 不要转圈（不要做踝关节环转），只有上下两个方向
- **【新增】腿绝对不能抬**：尤其患侧那条，从膝盖到脚跟全程压床，膝窝和床面不能有缝，绷脚尖也不能抬脚跟
- **【新增】校验方法**：播放视频时盯着患侧小腿下方看，如果能看到「床单」或「一条黑线/阴影」从腿下面露出来，就是错的

### 动作 2：握拳伸展（Fist Grip & Release）
**目的**：防止手指挛缩僵硬，维持手的基本抓握功能。
**剂量**：20 次/组 × 3 组，一天 2~3 次。

#### 提示词
```
医疗康复教学动画，2.5D 简约风格，特写视角（手掌占满画面）。
中老年人的右手（患侧，橙色袖套）手掌朝上或朝观众的方向，手腕放在一个软垫上固定。
特写镜头聚焦在手掌和手指上。

动作循环：
1. 起始位：五指自然伸直张开，手指之间有适度间隙，不要过度分开。
2. 慢慢握拳：从指尖开始，一根一根向掌心卷起来，先四指合拢，最后拇指压在食指和中指的指背上，握成一个放松的拳头，不要用力过猛挤压。停 0.5 秒。
3. 慢慢张开：按相反顺序，先拇指展开，再四指一根一根打开，回到五指完全伸直张开的状态，停 0.5 秒。
4. 重复。

节奏：非常缓慢，手指弯曲和伸展的过程清晰可见，完整一个循环约 3 秒。
细节：握拳时可以看到手背肌腱微微凸起（不要太夸张）；伸展时手指完全伸直但不后翘。
画面右下角文字：「张开到最大 · 握紧但不使劲」。
背景：柔和浅色桌面，无干扰。

======== 输出要求（不要忽略）========
【封面图】720×720 px 正方形 JPG，质量 85%，≤ 80KB，取「五指张开到最大幅度」的定格画面（动作顶点），保留右下角文字提示。
【短视频】MP4 / H.264 High Profile L3.1，960×540 px（或720×720 px），24 fps，时长精确3秒，1个完整循环，第一帧=最后一帧用于无缝循环，800~1200 kbps，无音轨，单文件 ≤ 400KB，删除所有元数据，全程静音。
```

#### 关键要点
- 张开要**充分**（五指尽量展开，撑到最大）
- 握拳要**放松**（不要握得指节发白，只是收拢成拳形）
- 如果患者自己做不了，后期可以叠加一个辅助手（家属的手）帮他一根一根轻轻掰开的画面，但先出主动作版本

### 动作 3：腕关节屈伸（Wrist Flexion & Extension）
**目的**：防止腕关节僵硬，维持手腕的上下活动范围。
**剂量**：20 次/组 × 2~3 组，一天 2 次。

#### 提示词
```
医疗康复教学动画，2.5D 简约风格，侧视特写视角（前臂最下端和手掌占满画面，肘关节不要入镜）。
中老年患者坐在床边，右前臂（患侧，橙色袖套）平放在桌上，手腕悬空在桌子边缘外，手掌自然下垂。
桌面只露出一小部分，画面聚焦手腕和手掌。

【这是腕关节动作——与肘关节严格区分，出错即重画】
- 关节定位：活动的关节是「手腕」（手掌和前臂连接的地方），不是「肘关节」（手臂中间那个大关节）。
- 肘关节和上臂全程完全不动，肘关节伸直锁定，上臂贴紧身体。
- 前臂（从肘到腕）全程平放在桌面上，像粘住一样固定，不抬起、不弯曲、不旋转、不画圈。
- 错误画面黑名单：肘关节弯曲、前臂离开桌面抬起、上臂晃动、前臂画圈、手腕 360° 旋转。
- 手腕只有两个方向：向上翘（手背朝向小臂）+ 向下垂（手掌朝向地面）。

动作循环（只有手腕动，其他地方全不动）：
1. 起始位：手腕放平，手掌和前臂在同一水平线上。
2. 手腕向上翘（背伸）：手掌用力向上（朝向天花板方向）翘起来，翘到有点紧的程度就停，不要压到疼，停 0.5 秒。
3. 回到水平位置，稍作停留。
4. 手腕向下垂（掌屈）：手掌用力向下（朝向地面方向）垂下去，垂到有点紧的程度，停 0.5 秒。
5. 回到起始位。

节奏：匀速缓慢，完整一个循环约 3.2 秒。
细节：前臂始终贴在桌面上不动，只有手腕关节在动；手腕关节处用浅色圆点标注；只有手腕的运动轨迹用淡蓝色虚线圆弧标注（约 ±50° 的范围）。
画面右下角文字：「手腕上下摆，不是转圈也不是弯胳膊」，文字全程不变、不模糊、不乱码。
背景：简洁桌面，无干扰。

======== 输出要求（不要忽略）========
【封面图】720×720 px 正方形 JPG，质量 85%，≤ 80KB，取「手腕向上翘到最大幅度」的定格画面（动作顶点），保留右下角文字提示。
【短视频】MP4 / H.264 High Profile L3.1，960×540 px（或720×720 px），24 fps，时长精确3.2秒，1个完整循环，第一帧=最后一帧用于无缝循环，800~1200 kbps，无音轨，单文件 ≤ 400KB，删除所有元数据，全程静音。
```

#### 关键要点
- **是上下摆，不是转圈**（不要做腕关节 360° 环转）
- 前臂必须固定住（放在桌上或床上垫稳），不能跟着甩
- 幅度：到有点紧就够了，不要追求掰到最大角度

### 动作 4：肘关节屈伸（Elbow Flexion & Extension）
**目的**：防止肘关节屈曲挛缩（弯久了伸不直），维持肘部屈伸范围。
**剂量**：15 次/组 × 2~3 组，一天 2 次。

#### 提示词
```
医疗康复教学动画，2.5D 简约风格，正面侧视 45° 视角，上半身入镜。

1. 起始位：手臂完全伸直，自然放在身侧，手心朝上或朝内。
2. 屈肘（弯起来）：前臂慢慢向上（朝向肩膀的方向）弯起来，肘关节角度逐渐变小，到手能碰到自己同侧肩膀附近即可，停 0.5 秒。

画面右下角文字：「伸直这一下更重要」。
背景：简洁病床，无干扰。

======== 输出要求（不要忽略）========
【封面图】720×720 px 正方形 JPG，质量 85%，≤ 80KB，取「手臂完全伸直」的定格画面（动作最关键位置），保留右下角文字提示。
【短视频】MP4 / H.264 High Profile L3.1，960×540 px（或720×720 px），24 fps，时长精确3.2秒，1个完整循环，第一帧=最后一帧用于无缝循环，800~1200 kbps，无音轨，单文件 ≤ 400KB，删除所有元数据，全程静音。
```

#### 关键要点
- **伸直这一下最重要**（别偷懒只弯不伸，肘挛缩就是伸不直）
- 可以加一个辅助元素：家属的一只手托在患者手腕和肘部下方，轻轻带着做（不要只拉着手）

### 动作 5：膝关节屈伸（Knee Flexion & Extension）
**目的**：防止膝关节僵硬，为日后坐、站打基础。
**剂量**：15 次/组 × 2~3 组，一天 2 次。

#### 提示词
```
医疗康复教学动画，2.5D 简约风格，45° 侧视病床视角，下半身入镜。
中老年患者平躺在病床上，双腿自然伸直，右腿（患侧，橙色裤腿）做动作，左腿（健侧，蓝色裤腿）自然伸直放在床上作为对照。

动作循环（脚全程不离开床面，脚掌贴着床滑动）：
1. 起始位：双腿完全伸直，脚掌平贴床面。
2. 屈膝（往回滑）：患侧脚的脚掌**贴着床面**，慢慢向自己屁股的方向滑动，膝盖随之立起来，弯曲到大腿和小腿约成 90° 或稍小的角度（能做到多少算多少），停 0.5 秒。
3. 伸膝（滑回去）：脚掌仍贴着床面，慢慢把腿滑回去，回到完全伸直的状态，停 0.5 秒。
4. 重复。

节奏：匀速缓慢，脚像被床吸住一样，完整一个循环约 3.4 秒。
细节：髋关节处和膝关节处用浅色圆点标注；小腿的滑动用淡蓝色水平虚线标注（强调脚不离床）。
画面右下角文字：「脚掌贴床面，不要抬起来」。
背景：简洁病床床单，无干扰。

======== 输出要求（不要忽略）========
【封面图】720×720 px 正方形 JPG，质量 85%，≤ 80KB，取「膝盖立起、脚滑到最近屁股位置」的定格画面（动作顶点），保留右下角文字提示。
【短视频】MP4 / H.264 High Profile L3.1，960×540 px（或720×720 px），24 fps，时长精确3.4秒，1个完整循环，第一帧=最后一帧用于无缝循环，800~1200 kbps，无音轨，单文件 ≤ 400KB，删除所有元数据，全程静音。
```

#### 关键要点
- **脚绝对不要离开床面**（贴着床滑，最省力最安全）
- 不需要刻意把膝盖抬很高，脚滑过来膝盖自然会立起来
- 不要把腿甩出去或用爆发力

### 动作 6：桥式运动（臀桥 / Glute Bridge）
**目的**：锻炼腰臀核心力量，为翻身、坐起、用便盆打基础。
**剂量**：维持 5 秒，10 个/组 × 3 组，一天 1~2 次。

#### 提示词
```
医疗康复教学动画，2.5D 简约风格，标准 45° 侧视病床视角，全身入镜。
中老年患者平躺在病床上，两腿屈膝，双脚脚掌踩实床面，两只手自然放在身体两侧。
头部和肩膀始终贴在床上，不要抬头。

动作循环：
1. 起始位：平躺，屈膝约 90°，脚掌踩实，臀部放松贴床。
2. 抬臀部：收紧屁股的肌肉，把臀部慢慢向上抬起来，直到肩膀、髋部、膝盖大致成一条斜线（不要过度拱腰），在最高点停 **1 秒**（画面中可加「停 5 秒」的大号文字叠加提示）。
3. 放下来：臀部慢慢回到床面，放松，停 0.3 秒。
4. 重复。

节奏：抬起过程缓慢，顶点停留明显，放下也要慢，不要砸床，完整一个循环约 3.6 秒。
细节：肩关节和髋关节用浅色圆点标注；向上的运动方向用绿色箭头标注；顶点位置用水平虚线辅助线标注「身体成一条斜线」。
画面右下角文字：「停 5 秒 · 不要憋气」，文字用绿色。
画面左侧人物口鼻处加小字：「正常呼吸」。
背景：简洁病床，无干扰。

======== 输出要求（不要忽略）========
【封面图】720×720 px 正方形 JPG，质量 85%，≤ 80KB，取「臀部抬到最高、身体成一条斜线」的定格画面（顶点位置），保留右下角文字和「正常呼吸」提示。
【短视频】MP4 / H.264 High Profile L3.1，960×540 px（或720×720 px），24 fps，时长精确3.6秒，1个完整循环，第一帧=最后一帧用于无缝循环，800~1200 kbps，无音轨，单文件 ≤ 400KB，删除所有元数据，全程静音。
```

#### 关键要点
- **顶点停留时间长**（真实做是 5 秒，动画里压缩到 1 秒但要让用户感觉到「这里要停」）
- **不要憋气**（这个动作最容易不自觉憋气，一定要提醒正常呼吸）
- 抬不起来也没关系，可以做「用力想抬但没抬起来」的版本作为进阶引导，但主版本是能抬起来的
- 肩膀和头全程贴床，不要用脖子使劲

### 动作 7：双手叉握上举（Bobath 握手）
**目的**：用好手带着患侧活动肩胛骨和肩关节，患者自己控制力度最安全。
**剂量**：10 次/组 × 2 组，一天 2 次。

#### 提示词
```
医疗康复教学动画，2.5D 简约风格，正面视角（人物面对观众），上半身入镜。
中老年患者坐在床上或床边，身体坐直，两只手在身体前方。

重点手部姿态特写（可以先给一个 1 秒的手部特写再拉远）：
- 双手十指交叉相握
- **右手（患侧，橙色袖套）的拇指压在左手（健侧，蓝色袖套）拇指的上面**（患侧拇指在上，这个细节一定要画对）

动作循环（两只手作为一个整体，从大腿位置往上举到胸口高度）：
1. 起始位：叉握好的双手放在大腿上，手臂自然放松。
2. 向上举：用好手带着患手，一起慢慢向上举起来，举到**胸口高度（大概和乳头齐平）就停下来**，不要继续往头顶方向举，停 0.5 秒。
3. 放下来：慢慢放回大腿上，停 0.3 秒。
4. 重复。

节奏：匀速缓慢，上升和下降过程都要稳，完整一个循环约 3.2 秒。
细节：肩关节处用浅色圆点标注；运动轨迹用淡蓝色虚线圆弧标注（从大腿到胸口的弧线）；在「胸口高度」处画一条水平虚线，并标注「举到这里就够，不要再往上」。
画面左下角文字：「患侧拇指在上」，用橙色。
画面右下角文字：「只举到胸口，不过头顶」。
背景：简洁病床，无干扰。

======== 输出要求（不要忽略）========
【封面图】720×720 px 正方形 JPG，质量 85%，≤ 80KB，取「双手举到胸口最高位置」的定格画面（动作顶点），同时保留左下角的「患侧拇指在上」和右下角提示文字，确保双手叉握特写清晰可见。
【短视频】MP4 / H.264 High Profile L3.1，960×540 px（或720×720 px），24 fps，时长精确3.2秒，1个完整循环，第一帧=最后一帧用于无缝循环，800~1200 kbps，无音轨，单文件 ≤ 400KB，删除所有元数据，全程静音。
```

#### 关键要点
- **患侧拇指在上**（这个是 Bobath 握手的标准姿势，不能画反）
- **只举到胸口高度**，绝对不要举过头顶（过肩有风险）
- 这是全套里唯一需要特别标注「肩膀疼就立刻停」的动作，可以在画面角落加一个小的红色疼痛警示图标作为提醒

### 动作 8：吹气球 / 缩唇呼吸（Pursed Lip Breathing）
**目的**：促进排痰，预防坠积性肺炎；零风险，推荐每天做。
**剂量**：15 分钟，一天 3~4 次。

#### 提示词
```
医疗康复教学动画，2.5D 简约风格，侧面特写视角（头部和上胸部入镜）。
中老年患者坐在床上，身体放松，侧脸对着观众。
面前有一根细长的吸管或直接吹一个粉色/浅红色气球，气球线轻轻握在一只手里。

动作循环（呼吸节奏：吸气 1 份，呼气 2 份）：
1. 起始位：放松，嘴唇微闭。
2. 用鼻子吸气：胸部和腹部微微隆起（可以看到躯干轮廓有一个轻微的扩大动画），吸气约 1 秒。
3. 撮唇吹气：嘴唇像吹蜡烛一样撮起来（缩成 O 形），对着气球或吸管慢慢把气吹出去，吹的过程比吸长一倍（约 2 秒），能看到气球慢慢变大，或用蓝色气流线表示气从嘴里流出。
4. 放松，稍作停顿，重复。

节奏：呼吸完整循环 4 秒，吸气短，呼气明显更长。
细节：气球大小随呼吸从小变大再变小（循环）；吹的气流用淡蓝色弯曲虚线表示，从嘴唇流向气球；胸口起伏可以用半透明叠加层显示轮廓变化。
画面右下角文字：「慢慢吹，吐气时间比吸气长一倍」。
气球旁边文字：「或者吹蜡烛、吹纸片，都行」。
背景：简洁卧室，窗外柔和光线，无干扰。

======== 输出要求（不要忽略）========
【封面图】720×720 px 正方形 JPG，质量 85%，≤ 80KB，取「气球吹到最大、正在呼气末」的定格画面（动作顶点），保留右下角和气球旁的提示文字。
【短视频】MP4 / H.264 High Profile L3.1，960×540 px（或720×720 px），24 fps，时长精确4秒，1个完整循环，第一帧=最后一帧用于无缝循环，800~1200 kbps，无音轨，单文件 ≤ 400KB，删除所有元数据，全程静音。
```

#### 关键要点
- **呼气时间是吸气的 2 倍**（这个比例关系要画出来）
- 不要用力猛吹，是「慢慢、长长地吐气」
- 如果吹气球觉得太费力，后期可以换成「面前摆一根蜡烛，吹得火焰晃动但不吹灭」的版本作为替代画面

## 三、生成时的额外建议

### 镜头与构图（适配微信小程序）
- 所有视频统一使用 **960×540（16:9 横屏）** 或 **720×720（正方形）**，8 个动作选一种就好，**不要混着来**
  - 推荐 720×720 正方形：在小程序的 `cover-view` 卡片、列表页、详情页、朋友圈分享里都能完美适配，不留黑边
- 主体人物占画面的 60%-70%，上方和左右留出 15% 安全区（避免被小程序胶囊按钮、导航栏、TabBar 裁切）
- 关键动作部位可以有 **1 秒以内的特写插入**（如双手叉握先给手部特写再拉远），但主镜头尽量保持固定，频繁运镜在手机小屏上会让老人晕

### 文字叠加规范（适配老人阅读）
- 字体：无衬线黑体（思源黑体 / PingFang SC / 微软雅黑），**不要用书法体、艺术体**
- 颜色色号（和你现有项目一致）：
  - 主提示文字：深蓝色 `#2a78d6`
  - 安全警示 / 红线：红色 `#c62f2f`
  - 鼓励信息 / 计时：绿色 `#0f8a2f`
  - 患侧提示：橙色 `#e88a3c`
- 字号：视频宽度的 1/10 以上（720 宽的视频，字号至少 72px 字高），背景可以加一个半透明白色圆角底衬，避免文字和背景糊在一起
- 位置：统一放在 **画面右下角 1/4 区域**，不遮挡关键关节动作；患侧/健侧颜色区分的说明放在左下角

### 可选进阶版（如预算/生成次数足够）
1. 每个动作做两个版本：
   - **标准版**：患者独立完成（用于详情页教学）
   - **家属辅助版**：画面中叠加一双手（浅肤色，比患者手稍大）在正确位置辅助，如肘屈伸托着手腕、膝屈伸扶着膝盖侧面（用于「不会做怎么办」的二级入口）
2. ~~开头加 1 秒文字卡~~ **不推荐**：小程序视频是静默自动播放的，开头 1 秒文字卡等于浪费用户加载的黄金时间，直接切入动作循环更友好
3. **不要加任何音频**（包括环境白噪音）：无音轨 MP4 才能 100% 静默自动播放（iOS 微信的限制）

### 微信小程序端的加载建议（给开发同学看）
1. **封面图 JPG 打进小程序包**（8 张 × 80KB ≈ 640KB，主包 2MB 限额内塞得下），首屏秒开不依赖网络
2. **MP4 统一放 CDN**，URL 类似 `https://cdn.xxx.com/rehab/v1/ankle-loop.mp4`
   - 小程序端用 `<video src="{{videoUrl}}" loop muted autoplay show-center-play-btn="{{false}}" controls="{{false}}" poster="{{coverUrl}}" />`
   - `poster` 属性一定要填，没加载完视频前显示封面图，用户感知不到加载
3. 页面进入时不自动加载所有 8 个视频，**用户点进详情页再加载当前那一个**，省流量也省内存
4. 视频 URL 加版本号（如 `ankle-loop-v1.mp4`），以后替换内容不用清缓存

### 生成后压缩命令（用 ffmpeg 一键达标）
如果 Seedance 导出的 MP4 编码不标准或体积超标，跑一遍下面的命令即可（以踝泵为例）：
```bash
# 封面图压缩（需要 ImageMagick）：720x720 JPG 质量 85%
magick input-cover.jpg -resize 720x720^ -gravity center -extent 720x720 -quality 85 -strip ankle-cover.jpg

# 视频转码：H.264 High L3.1 / 24fps / 无音轨 / 首帧对齐
ffmpeg -i input-video.mp4 \
  -c:v libx264 -profile:v high -level 3.1 -pix_fmt yuv420p \
  -r 24 -crf 25 -maxrate 1200k -bufsize 2400k -g 24 \
  -an -map_metadata -1 -movflags +faststart \
  -t 3.0 ankle-loop.mp4
```
