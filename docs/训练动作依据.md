## 你列的六个动作，核查结果

| 你说的 | 结论 | 说明 |
|---|---|---|
| 握拳伸展 | ✅ **采纳** | 手指小关节，无脱位风险。防手指挛缩最直接的办法 |

| 膝关节弯曲伸直 | ✅ **采纳** | 改成「脚掌贴床面滑动」，最省力最安全 |
| 踝关节屈伸 | ✅ **强烈采纳** | 即踝泵。零风险，且额外预防深静脉血栓。全套里最该每天做的 |

## 为什么「抬手」必须换掉

家属直接抬患侧手臂，是偏瘫最常见的致伤动作之一。三个机制（成都顾连锦宸康复医院康复科）：

1. **脱位**：肩部肌张力低，「难以有效稳定肱骨头」→ 肩关节半脱位
2. **撞击**：强行抬臂破坏肩肱节律，「肩峰下的结构被挤压或摩擦，进而引发撞击综合征」
3. **软组织损伤**：瘫痪肌肉「在被动牵拉时耐受能力较差」

而且卒中后肩痛**高发于发病后两个月内**——正是家属刚接手、最容易做错的窗口期。

原文的操作禁忌：避免「暴力牵拉」，禁止「用力过猛」，**先活动肩胛骨再活动肱骨**，
「出现疼痛应立即停止活动」，遵循「缓慢且平稳」。

### 替换方案：双手叉握上举（Bobath 握手）

这是全国老年健康教育服务平台推荐的做法，比家属被动抬手安全得多，原因是
**力度和范围由患者自己控制** —— 疼了他自己会停，这是天然的保护机制。

要点（原文）：**「患侧手拇指置于健侧手拇指上；摆动的时候要注意保护患侧肢体，避免幅度过大损伤关节」**

我们在此基础上加了一条更保守的限制：**先只举到胸口高度，不往头顶举**。

## 采纳的八个动作与出处

| 动作 | 剂量 | 主要出处 |
|---|---|---|
| 踝泵 | 20 次/组 × 3 组，一天 3 次 | 通用康复常识，多来源一致 |
| 握拳伸展 | 20 次/组 × 3 组 | 防挛缩，多来源一致 |
| 腕关节屈伸 | 20 次/组 × 2~3 组 | 同上 |
| 肘关节屈伸 | 15 次/组 × 2~3 组 | 同上 |
| 膝关节屈伸 | 15 次/组 × 2~3 组 | 同上 |
| **桥式运动（臀桥）** | **维持 5 秒，10 个/组，每次 3 组** | 全国老年健康教育服务平台（**原文剂量**） |
| **双手叉握上举** | 10 次/组 × 2 组 | 全国老年健康教育服务平台、澎湃新闻转载同源 |
| **缩唇呼吸 / 吹气球** | 缩唇 15~30 分钟，一天 3~4 次；吹气球 15~20 分钟，一天 5~6 次 | 全国老年健康教育服务平台（**原文剂量**） |

> 我们在产品里把呼吸训练的剂量收敛成「15 分钟，一天 3~4 次」——
> 取原文区间的下限，对高龄患者更稳妥。

呼吸训练值得特别说：**它零风险，而且直接对着我们最强调的那个死因**——
坠积性肺炎 / 卒中相关性肺炎（急性期发生率 7%~22%）。高龄共识里也把
「促进排痰」列为急性期物理治疗内容之一。

## 统一的停止信号（多来源一致）

- 出现**疼痛** → 立刻停
- 出现**头晕、乏力、气短、脸色发白** → 停下休息
- 全程**不要憋气**（桥式运动原文特别强调「保持正常呼吸，整个过程不要憋气」）
- 慢、稳，**不要甩、不要用猛劲**
- 第二天比平时更累 → 说明昨天做多了，减量

原文表述：「若出现疲劳、乏力、头晕等，应减少训练时间、次数或者暂时停止训练」

## 仍然不做的

| 不做 | 原因 |
|---|---|
| **站立训练、步行训练** | 跌倒 → 老年髋部骨折 → 一年内死亡率极高。高龄共识明确指出「中风后跌倒率较健康老年人大幅提升」 |
| **吞咽训练** | 误吸 → 可直接致命。我们只讲**进食安全**（坐直、下巴微收、小口慢喂），不讲吞咽训练 |
| **被动上举患侧手臂过肩** | 见上 |
| **根据打卡自动加量** | 需要评估肌张力和心肺功能，软件判断不了 |
| **任何功能评分与预后判断** | 属医疗评定 |

## 关于「多图少字」用不用 3D

结论：**3D 不是这里的正解，动起来才是。**

- 3D 渲染带来阴影、透视、材质，对老年人和低识字度用户是**噪音**，不是信息
- 动作有**时间维度**，静态图无论 2D 还是 3D 都丢失了这一维
- 所以当前用的是 **2D 线稿 + 循环动画（SVG/CSS）**：文件小、能离线、易迭代、
  并且尊重系统的「减弱动态效果」设置
- **真正的天花板是真人短视频**——但那需要康复师配合拍摄。等找到人再做
