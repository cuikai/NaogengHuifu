# 上线前检查清单

分成三档：**A 不做完不能上线**、**B 上线后一个月内补**、**C 想清楚再做**。

---

## A · 不做完不能上线

### A1　康复治疗师逐条签字

必须有执业康复治疗师（最好再加一位神经内科医师）**逐条**过一遍并签字留档：

- [ ] `utils/poses.js` 14 个动作的关键帧 —— 建议用 `node tools/check-figure.js --table` 打出关节角度表逐帧看
- [ ] `utils/library.js` 的 `LADDER` 进阶阶梯与 `BASE_SETS` 基础组数
- [ ] `utils/cards.js` 11 张知识卡全文
- [ ] `utils/assess.js` 的 `FLAG_RULE`，特别是标了 `urgent` 的四条
- [ ] `utils/adl.js` 的 `STOP` 与 `CALL` 两档停止信号
- [ ] `utils/evidence.js` 每个动作的依据表述有没有把话说满

v2 新增了站立与步行内容（v1 刻意回避了这块）。**跌倒风险必须由专业人把关**，这是签字环节里权重最高的部分。

### A2　跑完三个自动检查

```bash
node tools/check-figure.js      # 动作数据体检：角度越界、脚陷地面、扶手够不到、停够没停够
node tools/smoke.js             # 端到端：快筛 → 出计划 → 打卡 → 升降级 → 跨天 → 复评
node tools/check-figure.js --table   # 给治疗师逐帧复核用
```

三个都必须全绿。`check-figure` 查的是「照着练会出事」的错误。

### A3　真机与老人可用性

- [ ] 小屏（iPhone SE 一档）和大屏各跑一遍，正文的**物理大小**接近一致（`app.js` 的 `--fs` 系数）
- [ ] 找 2～3 位 60 岁以上、不是本项目相关的人，不给任何提示，看他们能不能独立走完：打开 → 快筛 → 找到今天练什么 → 做完一组 → 打反馈
- [ ] 特别看：他们认不认得左上角的返回箭头（`move` 页已经为此把主按钮做成了出口）
- [ ] 深色模式已在 `app.json` 关闭（`darkmode: false`），确认没有页面依赖系统色

### A4　合规文案自查

- [ ] 全站搜一遍「处方」「方案」「疗效」「治疗」「有效率」「分级」「评分」，确认没有漏网
- [ ] 界面上不出现 M/H 的数字
- [ ] 「用户隐私保护指引」按微信流程填好

## B · 上线后一个月内补

- [ ] **急性期的处理再想一层。** 现在的做法是「勾了不到 2 周 → 拿掉单腿站立 + 阶梯钉在第 0 档 + 满 14 天自动解除」。这是个折中：快筛只问了档位、没问具体日期，所以只能用「做快筛那天 + 14 天」兜底。更准的做法是直接问发病日期，但会多一步录入。上线后看数据再定。
- [ ] **`situp` 这道题的用途。** 现在只用于封顶（勾「完全坐不起来」→ M1）。它本可以驱动床上转移的内容，但库里还没有相应动作。
- [ ] **失语用户的路径。** 快筛全是文字题。勾了「说话说不清」的用户，家属能代答，但用户本人用不了。至少该给语音朗读。
- [ ] **偏侧忽略（半侧空间忽略）没有覆盖。** 这类患者会撞到患侧的东西、只吃半边盘子里的饭，是跌倒和误吸的独立风险因素。现在只在「看东西重影」那条标记里擦了个边。
- [ ] **照顾者的负担。** `mood` 卡最后一条提了一句「照顾的人也会垮」，但没有任何后续路径。照护者抑郁的发生率不低于患者。

## C · 想清楚再做

- **要不要接入可穿戴设备读血压心率。** 现在靠家属手动量、手动看。接了会准很多，但立刻踩到医疗器械的边界，且引入第三方 SDK（现在是零 SDK）。
- **要不要让治疗师远程看数据。** 一旦有专业人看，产品性质从「工具」变成「服务」，合规要求完全不同。
- **要不要做社区/病友交流。** 卒中后抑郁的数据支持社会连接的价值，但 UGC 医疗信息的审核成本极高，且会把「每条都能核到出处」这个立身之本破坏掉。

---

## 每次改动内容之后的固定动作

1. 改 `utils/poses.js` → 必须跑 `node tools/check-figure.js`
2. 改 `utils/assess.js` / `plan.js` / `store.js` → 必须跑 `node tools/smoke.js`
3. 改 `utils/cards.js` 里的任何医学声明 → 同步更新 `docs/证据与来源.md`，核不到出处就不要写
4. 改 `assess.QUIZ[7].opts`（安全标记） → **只能往后追加，不能插入、不能重排**。本地存的是下标，重排会让老用户的标记全部错位
