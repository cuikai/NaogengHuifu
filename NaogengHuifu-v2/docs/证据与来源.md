# 证据与来源

代码里每一条医学声明的出处。**核不到出处的话不写进产品。**

写这份文件的规矩有三条：

1. 能核到指南原文的，写指南名称、推荐意见编号、证据等级。
2. 属于常规实践、没有专门指南推荐的，**明说是常规实践**，不要冒充指南。
3. 证据本身弱的（比如口腔护理与肺炎），**把弱说出来**。把弱证据说成强证据，比不写更糟。

最后一次核对：2026-09。核对人：待康复治疗师签字（见 `docs/上线前检查清单.md`）。

## 二、适用性与运动安全（`cards.js` → `fit`；`assess.js` → `FLAG_RULE`）

| 声明 | 出处 |
|---|---|
| 远程康复适用条件（诊断明确、病情稳定、无严重并发症、能配合指令、有社会支持、本人愿意） | 2025 年远程康复专家共识，意见 1，证据质量中、强推荐；并写明存在远程康复禁忌证者不推荐使用 |
| 运动安全监测窗：收缩压 110～220 mmHg、心率 40～110 次/分、血氧 ≥92%、体温 36.0～38.5℃ | 《成人脑卒中患者运动康复循证实践指南》（中国康复医学会循证康复医学工作委员会） |
| 产品内收窄为收缩压 110～180、心率 50～100 | **这是我们自己收的**，不是指南数值。理由：家里没有专业人在旁边，且指南的窗是给有监护的场景用的 |
| 终止指征：疲倦、恶心、头痛、眼球震颤 → 立即停止并重新评估 | 同上 |
| **绝对禁忌**：急性深静脉血栓、急性肺栓塞、近期心肌梗死（2 周内）、不稳定心绞痛、未控制的症状性心衰、急性感染、未经医学评估的外伤性跌倒 | PARAS《Contraindications to moderate or vigorous exercise after stroke》(2025) 绝对禁忌清单 |
| 相对禁忌的血压门槛 SBP >200 / DBP >110 | 同上（我们取了更保守的 180） |

### ⚠️ 本次最重要的一条安全修正

原 `FLAG_RULE[1]`（手脚肿）的处置是「**踝泵每天多做一组**」。

单侧下肢肿胀 + 疼痛 + 皮温升高是深静脉血栓的典型表现，而**急性深静脉血栓是卒中后运动的绝对禁忌证**（PARAS 2025）。对疑似血栓的患肢增加主动踝泵、或按摩患肢，有把血栓推成肺栓塞的风险。

现改为：先分辨双侧/单侧 → 双侧对称多为卧床性水肿，踝泵照常 → 单侧 + 疼 + 发烫则当天停练、就医、**不要按摩那条腿**。UBC 的 DVT 活动临床实践指南同样要求：未开始治疗性抗凝之前，所有活动指令都须与医生核实。

## 三、误吸与肺炎（`cards.js` → `feed`）

| 声明 | 出处 |
|---|---|
| 卒中急性期肺炎发生率 7%～22% | 《卒中相关性肺炎诊治中国专家共识（2019 更新版）》原文 |
| 住院后 24 h 内应完成吞咽障碍筛查 | 《卒中相关非运动症状多学科管理专家共识》 |
| 坐直 90°、下巴微收、小口慢喂、饭后坐 30 分钟 | 吞咽障碍照护的通行做法 |
| 口腔清洁 | **证据弱，产品里已注明**。Cochrane CD003864（15 项 RCT、1546 例）评为低到很低质量证据，未能证实口腔护理总体上减少肺炎；其中一项清洁凝胶研究见到肺炎减少（OR 0.20, P=0.028）。写入产品的理由是成本近零、无害，不是因为证据充分 |

## 七、训练剂量与时机（`cards.js` → `dose`；`utils/evidence.js`）

| 声明 | 出处 |
|---|---|
| 有氧每周 3～5 次、每次 20～40 分钟、中等至高强度 | 《成人脑卒中患者运动康复循证实践指南》推荐意见 6，证据等级 1B |
| 从低强度开始、循序渐进 | 同上，推荐意见 1-2，1B |
| 运动前需全面评估 | 同上，推荐意见 2-1，1A |
| 生命体征稳定、症状不再进展前提下，发病 24～48 h 后尽早启动 | 同上，推荐意见 1-1，1B |
| **发病 24 h 内高强度离床活动可能有害** | AVERT 试验（Lancet 2015，n=2104）；Cochrane CD006187 亦指出 24 h 内密集活动对部分患者可能带来风险 |
| 每个动作的组数/次数 | **常规康复实践**，落在抗阻训练常用的 1～3 组 × 8～20 次区间内。没有任何指南规定「踝泵每组 20 次」，`utils/evidence.js` 里对每个动作逐条写明了这一点 |
| 进阶顺序：先加量 → 再减支撑 → 最后加幅度和速度 | 常规实践。先加安全的那一维，最后加最容易摔的那一维 |
| 关节角度 | 步态各时相髋/膝/踝角度取自 Perry《Gait Analysis》常用值；坐站转移、踝泵、桥式取自常见活动度参考值 |

## 八、居家环境改造（`cards.js` → `home`）

《脑卒中患者居家康复环境评估与改造实践指南（2025 ICF 版）》，中国康复医学会社区康复工作委员会。红黄绿三色优先级、温湿度（20～26℃ / 40%～60%）、照明要求、一键紧急呼叫、4～6 周复评周期均为指南内容。

## 九、体位与转移（`cards.js` → `lift` / `move` / `dress`）

肩关节半脱位与偏瘫后肩痛的成因包含关节囊粘连、肩关节半脱位、肩手综合征、误用综合征 —— 即「用错了」本身就是病因之一。故所有搬动一律托肩胛与腰，禁止牵拉患侧上肢；患侧不量血压、不扎针。

## 已知的证据缺口（不要假装没有）

- 踝泵能否降低卒中患者 DVT 发生率，缺高质量证据。写入产品是因为近乎零风险，不是因为有效性已证实。
- 口腔护理与卒中相关性肺炎，见第三节，证据质量低。
- 每个动作的具体次数/组数没有针对性 RCT，属编排。真正调节强度的是用户反馈驱动的升降级，不是这些初始数字。
- 双轴（M/H）分层的切分点是产品设计，不是任何一个标准量表的分级。**界面上不出现分数、不出现分期**，见 `docs/合规边界.md`。
